# Custom Neural Network with Manual Backpropagation

This repository contains a NumPy implementation of a feedforward neural network trained with manual backpropagation. Autograd frameworks are **not** used in the main network implementation.

## Project Structure
* `nn_from_scratch.py`: Core neural network model, forward pass, and manual gradient computation.
* `test_correctness.py`: Automated correctness harness comparing manual gradients to `torch.autograd`.
* `train.py`: Training script demonstrating loss minimization over epochs.
* `WRITEUP.md`: Comprehensive engineering report and mathematical derivations.
